# 第三方工具使用安全规则

1. **公开仓库**：别在此仓库存储任何个人手机号、身份信息、班级名单、Token、Cookie、密钥、会话截图或个人记录。
2. **Skills 不等于可信程序**：阅读指令与所需权限，再决定是否执行联网或系统命令。
3. **先审阅依赖**：`npx`、`npm i`、`pip install` 和 Git 子模块都会引入第三方内容。确认其源码、版本、维护状态及授权。
4. **避免越权网页操作**：不要让浏览器自动化未经同意访问他人的账户、搜集私人数据或发送消息。
5. **GhostTrack**：只在有合法权限的目标上研究网络公开数据。不拿它骚扰、监控、跟踪或推断他人实时位置；结果可能错误或过时。
6. **分支保护**：批量修改前先建立可恢复的提交与分支。删除、泄露或替换敏感数据可能无法撤销。
